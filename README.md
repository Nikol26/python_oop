# Лабораторная работа №3 — Наследование и иерархия классов

## 1. Цель работы

Освоить механизм наследования классов, научиться строить иерархию объектов,  
переиспользовать код базового класса и переопределять методы.  
Изучить полиморфизм и создание общего интерфейса для работы  
с разными типами объектов через базовый класс.

3. Демонстрация работы

Демонстрация состоит из шести сценариев в файле demo.py.

Сценарий 1: Наследование

Создаются объекты трёх производных классов:

BachelorStudent
MasterStudent
PhDStudent

Демонстрируется:

работа конструкторов с использованием super()
наследование атрибутов и методов базового класса
вывод объектов через переопределённый __str__()
различия в представлении для каждого типа студента
Сценарий 2: Методы базового и дочерних классов

Показывается использование:

базового метода promote()
дочернего метода choose_elective() у бакалавра
дочернего метода submit_research_plan() у магистра
дочернего метода publish_article() у аспиранта

Этот сценарий демонстрирует, что дочерние классы получают общий функционал
базового класса и при этом имеют собственные методы.

Сценарий 3: Работа с коллекцией

Создаётся коллекция StudentCollection, содержащая объекты разных типов:

BachelorStudent
MasterStudent
PhDStudent

Демонстрируется:

хранение разных типов объектов в одной коллекции
корректная работа коллекции с наследниками базового класса
повторное использование коллекции из ЛР-2
Сценарий 4: Полиморфизм

Демонстрируется полиморфный вызов общего метода:

student.display()

Каждый объект использует один и тот же интерфейс, но результат разный:

бакалавр выводит направление и форму обучения
магистр выводит программу и область исследования
аспирант выводит тему работы и научного руководителя
Сценарий 5: Проверка типов

Используется isinstance() для определения типа объекта в коллекции.

Демонстрируется:

проверка принадлежности к BachelorStudent
проверка принадлежности к MasterStudent
проверка принадлежности к PhDStudent
Сценарий 6: Фильтрация по типу

Показывается взаимодействие с коллекцией:

get_only_bachelors() — выборка только бакалавров
get_only_masters() — выборка только магистров
get_only_phd() — выборка только аспирантов

Этот сценарий демонстрирует интеграцию наследования с коллекцией из ЛР-2.
