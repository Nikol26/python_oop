## 3. Описание CLI

Приложение запускается командой:

python python_labs/src/lab07/main.py

В приложении реализовано меню:

1. Добавить студента
2. Показать всех студентов
3. Найти студента
4. Удалить студента
5. Фильтр по GPA
6. Сортировка
7. Перевести на следующий курс
8. Обновить GPA
0. Выход

Приложение работает в цикле: после выполнения действия меню показывается снова.
Обработка ошибок

Если пользователь вводит не число вместо пункта меню, программа выводит:

Ошибка: введите число

Если выбран несуществующий пункт меню, программа выводит:

Ошибка: такого пункта меню нет

Также обрабатываются ошибки предметной области:

студент не найден;
студент уже существует;
некорректный курс;
некорректный GPA;
пустое имя или группа.
Сохранение и загрузка

При запуске приложение автоматически загружает данные из JSON-файла.

При выходе через пункт 0 данные автоматически сохраняются.

Файл с данными:

python_labs/src/lab07/data/students.json
