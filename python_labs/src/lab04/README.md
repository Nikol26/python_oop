# Лабораторная работа №4 — Интерфейсы и абстрактные классы (ABC)

## 1. Цель работы

Познакомиться с абстрактными базовыми классами ABC, изучить понятие интерфейса как контракта поведения и научиться задавать обязательные методы для классов.

В данной лабораторной работе закрепляется полиморфизм через единый интерфейс и проектирование архитектуры программы, где разные объекты могут обрабатываться одинаково.
## 2. Описание интерфейсов

В лабораторной работе созданы два интерфейса: Printable и Comparable.

### Интерфейс Printable

Интерфейс Printable задаёт общий контракт для объектов, которые можно вывести в текстовом виде.

Обязательный метод:

- to_string() — возвращает строковое описание объекта.

Данный интерфейс используется для единого вывода информации о студентах разных типов.

### Интерфейс Comparable

Интерфейс Comparable задаёт общий контракт для объектов, которые можно сравнивать между собой.

Обязательный метод:

- compare_to(other) — сравнивает текущий объект с другим объектом.

Метод возвращает:

- 1, если текущий объект больше;
- -1, если текущий объект меньше;
- 0, если объекты равны.
 ## 3. Реализация в классах

Интерфейсы реализованы в следующих классах:

- PrintableBachelorStudent
- PrintableMasterStudent
- PrintablePhDStudent

Данные классы наследуются от классов из лабораторной работы №3 и дополнительно реализуют интерфейсы Printable и Comparable.

### Класс PrintableBachelorStudent

Реализует методы:

- to_string() — выводит информацию о бакалавре;
- compare_to(other) — сравнивает объекты по GPA.

Дополнительно выводятся:

- направление подготовки;
- форма обучения.

### Класс PrintableMasterStudent

Реализует методы:

- to_string() — выводит информацию о магистре;
- compare_to(other) — сравнивает объекты по GPA.

Дополнительно выводятся:

- программа обучения;
- область исследования.

### Класс PrintablePhDStudent

Реализует методы:

- to_string() — выводит информацию об аспиранте;
- compare_to(other) — сравнивает объекты по GPA.

Дополнительно выводятся:

- тема исследования;
- научный руководитель.

### Отличия поведения классов

Все классы имеют одинаковые методы интерфейсов, но выводят разную информацию в зависимости от типа студента.

Это демонстрирует полиморфизм: один и тот же метод работает по-разному у разных объектов.

В данной лабораторной работе сравнение выполняется по среднему баллу GPA.
