# Лабораторная работа №6 — Generics и typing

## 1. Цель работы

Освоить систему аннотаций типов в Python и научиться создавать обобщённые классы с помощью TypeVar и Generic.

В ходе лабораторной работы были изучены:

- аннотации типов;
- модуль typing;
- обобщённые классы Generic;
- переменные типов TypeVar;
- второй TypeVar для изменения типа результата;
- Callable;
- Optional;
- Protocol;
- структурная типизация;
- ограничение TypeVar через bound.

Лабораторная работа построена на основе предыдущих работ:

- ЛР-1 — базовая модель предметной области;
- ЛР-2 — коллекция объектов;
- ЛР-3 — иерархия классов студентов.
