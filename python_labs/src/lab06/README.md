## 2. Описание реализованных типов и контейнеров

Generic — это механизм создания обобщённых классов. Он позволяет одному классу работать с разными типами данных. В лабораторной TypedCollection(Generic[T]) означает, что коллекция может хранить объекты любого типа, но внутри одной коллекции все объекты должны быть одного типа.

В лабораторной работе реализован generic-контейнер:

```python
TypedCollection[T]
```
TypedCollection — это типизированная коллекция, которая может хранить объекты определённого типа.

Например:
```python
collection: TypedCollection[Displayable]
```
означает, что коллекция предназначена для объектов, которые соответствуют протоколу Displayable.

2.1. TypeVar T

TypeVar — это переменная типа, которая используется для создания generic-классов и generic-функций. Она позволяет писать универсальный код, который может работать с разными типами данных. Например, T = TypeVar("T") означает, что T — это некоторый тип, который будет определён позже. В лабораторной работе TypeVar используется в классе TypedCollection(Generic[T]), чтобы коллекция могла хранить объекты любого типа, но внутри одной коллекции тип должен быть одинаковым. Например: TypedCollection[str], TypedCollection[int], TypedCollection[Student].

В файле container.py создана переменная типа:

T = TypeVar("T")

Она используется для обозначения типа элементов внутри коллекции.

Пример:
```python
class TypedCollection(Generic[T]):
```
Это значит, что TypedCollection является обобщённым классом и может работать с разными типами объектов.
2.2. TypeVar R

Также создана переменная типа:
```python

R = TypeVar("R")
```

Она используется в методе map().

Метод map() может преобразовывать элементы коллекции в значения другого типа.

Пример:
```python
def map(self, transform: Callable[[T], R]) -> list[R]:
```
Это значит:

- на вход функция получает объект типа T;
- на выход возвращает объект типа R;
- итоговый результат — список list[R].

В демонстрации показано:

- map() возвращает list[str] — список имён;
- map() возвращает list[float] — список GPA.
2.3. Protocol Displayable

В работе реализован протокол:
```python
class Displayable(Protocol):
    def display(self) -> str:
        ...
```
Displayable описывает объект, который умеет возвращать строковое представление через метод display().

Если у объекта есть метод display(), значит он подходит под этот протокол.

2.4. Protocol Scorable

Protocol — это механизм структурной типизации в Python. Он описывает, какие методы должен иметь объект. Главное отличие Protocol в том, что объекту не нужно наследоваться от него явно. Если у объекта есть нужные методы, значит он автоматически подходит под этот Protocol. Например, если Protocol Displayable требует метод display(), то любой объект с методом display() считается Displayable. В лабораторной работе используются Protocol Displayable и Scorable.

Также реализован протокол:
```python
class Scorable(Protocol):
    def score(self) -> float:
        ...
```
Scorable описывает объект, который умеет возвращать числовую оценку через метод score().

В моей работе метод score() возвращает GPA студента.

2.5. Ограниченные TypeVar

Для протоколов созданы ограниченные переменные типов:
```python
D = TypeVar("D", bound=Displayable)
S = TypeVar("S", bound=Scorable)
```
Они показывают, что тип должен соответствовать определённому протоколу.

D подходит только для объектов, у которых есть метод display().

S подходит только для объектов, у которых есть метод score().

2.6. Методы TypedCollection

В классе TypedCollection реализованы методы:

- add(item: T) -> None

Добавляет объект в коллекцию.

- remove(item: T) -> None

Удаляет объект из коллекции.

- get_all() -> list[T]

Возвращает список всех объектов коллекции.

- find(predicate: Callable[[T], bool]) -> Optional[T]

Ищет первый объект, подходящий под условие.

Если объект найден — возвращает его.

Если объект не найден — возвращает None.

- filter(predicate: Callable[[T], bool]) -> list[T]

Возвращает список всех объектов, которые подходят под условие.

- map(transform: Callable[[T], R]) -> list[R]

Применяет функцию к каждому объекту и возвращает список результатов.

Тип результата может отличаться от типа объектов коллекции.

- sort_by(key_func: Callable[[T], object], reverse: bool = False) -> TypedCollection[T]

Сортирует коллекцию по переданной функции.

- apply(func: Callable[[T], R]) -> list[R]

Применяет переданную функцию ко всем элементам коллекции.

2.7. Классы студентов

В demo.py созданы классы:

- TypedBachelorStudent;

- TypedPhDStudent.

Они основаны на классах из ЛР-3:

- BachelorStudent;
- MasterStudent;

Каждый класс реализует методы:
```python

```

При этом классы не наследуются явно от протоколов Displayable и Scorable.

Они подходят под протоколы по наличию нужных методов.

Это демонстрирует структурную типизацию.
