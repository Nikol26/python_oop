Освоить механизм наследования классов, научиться строить иерархию объектов,

## 2. Описание реализованной иерархии классов

В работе используется предметная область — студенты.

### Базовый класс Student

Атрибуты:
- _name — имя студента  
- _student_id — ID  
- _course — курс  
- _gpa — средний балл  
- _status — статус  

Методы:
- promote() — перевод на следующий курс  
- expel() — отчисление  
- display() — общий интерфейс вывода  
- __str__() — строковое представление  
- __repr__() — представление для разработчика  
- __eq__() — сравнение объектов  

---

### Дочерний класс BachelorStudent

Дополнительные атрибуты:
- _major — направление  
- _study_form — форма обучения  

Новый метод:
- choose_elective() — выбор элективного курса  

Переопределение:
- display()  
- __str__()  
Переопределение — это когда в дочернем классе ты пишешь метод с тем же именем, но он работает по-другому
---

### Дочерний класс MasterStudent

Дополнительные атрибуты:
- _program_name —  название программы
- _research_area — область исследования  

Новый метод:
- submit_research_plan() — отправка исследовательского плана  

Переопределение:
- display()  
- __str__()  

---

### Дочерний класс PhDStudent

Дополнительные атрибуты:
- _thesis_topic — тема  
- _supervisor — научный руководитель  

Новый метод:
- publish_article() — публикация статьи  

Переопределение:
- display()  
- __str__()  

---

### Различия между классами

| Класс            | Доп. данные        | Метод                      | Особенность     |
|------------------|-------------------|----------------------------|-----------------|
| Student        | —                 | базовый                    | общий функционал |
| BachelorStudent`| направление       | `choose_elective()        | бакалавр        |
| MasterStudent  | программа         | submit_research_plan()   | магистр         |
| PhDStudent     | тема              | publish_article()        | аспирант        |
