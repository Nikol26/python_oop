# Лабораторная работа №3 — Наследование и иерархия классов

## 1. Цель работы

Освоить механизм наследования классов, научиться строить иерархию объектов,  
переиспользовать код базового класса и переопределять методы. Изучить полиморфизм  
и создание общего интерфейса для работы с разными типами объектов через базовый класс.

## 2. Описание реализованной иерархии классов

В работе используется предметная область — студенты.

Построена следующая иерархия:
Student
├── BachelorStudent
├── MasterStudent
└── PhDStudent
---

### Базовый класс Student

Атрибуты:
- _name — имя студента  
- _student_id — ID  
- _course — курс  
- _gpa — средний балл  
- _status — статус  

Методы:
- promote() — перевод на следующий курс  
- expel() — отчисление  
- display() — общий интерфейс вывода  
- __str__() — строковое представление  
- __repr__() — представление для разработчика  
- __eq__() — сравнение объектов  

---

Дополнительные атрибуты:

Новый метод:

Переопределение:
- display()  
- __str__()

### Дочерний класс MasterStudent
